# Расчёт доходности и оптимизация распределения средств по банковским вкладам

Курсовая работа по дисциплине «Технология разработки программных систем»,
МГТУ им. Н.Э. Баумана, кафедра ИУ6. Выполнил А.А. Шабрин, гр. ИУ6-55Б; руководитель М.В. Фетисов.
Веб-приложение: Python + Flask (шаблоны Jinja2), SQLite без ORM, numpy.
Работает локально: сервер слушает только адрес `127.0.0.1:5000`, доступа с других компьютеров нет
(кроме демонстрационного режима, см. ниже).

## Требования

- **Компьютер:** архитектура x86-64 или ARM64, двухъядерный 64-разрядный процессор от 1 ГГц,
  оперативная память от 4 Гбайт, 200 Мбайт свободного места без учёта среды выполнения.
- **Операционная система:** Windows 10 или 11; Linux (Ubuntu 22.04 LTS и выше или совместимый
  дистрибутив); macOS 12 и выше.
- **Среда выполнения:** Python 3.10 или новее (python.org; в Linux — пакеты `python3` и `python3-venv`).
- **Браузер:** Google Chrome 110+, Microsoft Edge 110+, Mozilla Firefox 110+ или Safari 16+.
- **Интернет** нужен при первом запуске — для установки библиотек из `requirements.txt` — и для
  получения сведений ЦБ РФ. Без подключения система работает на последних сохранённых сведениях.

## Установка и запуск

- **Windows:** дважды щёлкнуть `run_windows.bat`.
- **Linux / macOS:** в терминале из папки проекта выполнить `./run_unix.sh`.

При первом запуске скрипт создаёт окружение `.venv` и устанавливает библиотеки (Flask, numpy).
Затем открывается браузер со страницей http://127.0.0.1:5000. Остановка — Ctrl+C в окне консоли
(в Windows на вопрос «Terminate batch job (Y/N)?» ответить Y).

Запуск вручную:

    python -m venv .venv
    .venv/bin/pip install -r requirements.txt        (Windows: .venv\Scripts\pip ...)
    .venv/bin/python run.py                           (--offline — не обращаться к сайту ЦБ)

## Демонстрационный режим (показ на других устройствах)

Чтобы другие люди открыли Систему на своих телефонах и ноутбуках, подключённых к той же сети
Wi-Fi, запустите `run_demo_windows.bat` (Linux/macOS: `./run_demo_unix.sh`) или
`python run.py --share`. В окне консоли появится адрес вида `http://192.168.1.15:5000/` —
его нужно открыть на другом устройстве. Если Windows спросит про доступ к сети, разрешите его для
частных сетей. Работает, пока запущена программа на вашем компьютере.

Это отступление от п. 4.4.1 ТЗ (доступ только с этой же ЭВМ) — только для показа работы.
Обычный запуск (`run_windows.bat`) по-прежнему доступен только с этого компьютера.

## Справочник

Файл `database/deposits.db` ведётся внешними средствами работы с базой данных
(например, DB Browser for SQLite). Перед изменением сделайте копию файла; обновляйте справочник
не реже раза в 30 дней. В справочник вносятся только банки — участники системы страхования
вкладов; у каждого банка должен быть заполнен уникальный номер лицензии ЦБ РФ.

В поставке — справочник из 20 банков и 316 вкладов: условия вкладов собраны с сайтов банков
по состоянию на 12–16.10.2026. Каждая пара «срок — ставка» продукта банка — отдельная запись.
Сведения носят учебный характер и могли устареть: перед размещением средств условия нужно
сверить на сайте банка.

Для проверки на других данных:

    python tools/init_db.py --force            небольшой демонстрационный справочник: 8 банков, 19 вкладов
                                               (заменяет database/deposits.db — сделайте копию)
    python tools/generate_catalog.py 1000      синтетический справочник на 1000 вкладов → database/catalog_1000.db
    python run.py --db database/catalog_1000.db

## Структура проекта

    app/
      ui/                  подсистема пользовательского интерфейса: маршруты Flask, проверка ввода,
                           текстовый отчёт, шаблоны страниц, стили, клиентский сценарий
      data_management/     подсистема управления данными: чтение справочника, контроль целостности,
                           отбор вкладов
      yield_calc/          подсистема расчёта доходности: доход по вкладу, НДФЛ, застрахованная часть
      optimization/        подсистема оптимизации распределения: точный (ДП) и приближённый
                           (жадный) методы, дискретизация
      external_sources/    подсистема взаимодействия с внешними источниками: сведения ЦБ РФ
      models.py            структуры данных, которыми обмениваются подсистемы
    database/              схема БД, демонстрационные данные, файл справочника
    tests/                 автоматические тесты
    tools/                 создание БД и генератор синтетического справочника
    run.py                 средство запуска
